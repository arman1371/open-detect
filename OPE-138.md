# OPE-138: Re-implement Raha factorize-once strategies (P-11) from scratch

## Objective
Re-implement all four strategy families (histogram outlier, gaussian outlier, pattern characters, FD violations) around a single `_factorize_column()` helper so each column is stringified + `pd.factorize()`d once and the integer codes are reused across every strategy.

## Implementation Status
**COMPLETE**

### What Was Done
- **Rewrote all four strategy families** in `src/open_detect/algorithms/raha/strategies.py` around a single `_factorize_column()` helper
