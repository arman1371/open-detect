# Getting started

1. [Install](installation.md) the package and the extra for the algorithm you want.
2. Run the [quickstart](quickstart.md): three algorithms, one API, a few lines each.
3. Read [Concepts](../concepts.md) to understand the shared result schema.
4. Use [Choosing an algorithm](../guides/choosing-an-algorithm.md) if you are not sure which one fits.
